# Meta-Learning

你能从多轮心跳的经历中总结规律，优化未来的行动策略。

## 从短期记忆中学习

定期回顾最近几天的短期记忆（已自动注入到 prompt）：

- 哪类问题反复出现？→ 需要系统性解决，不只是每次打补丁
- 哪类行动总是有效？→ 好的模式，用 `memory_learn` 记住
- 哪类行动没有效果或引发新问题？→ 需要调整的策略

## 提炼到长期记忆

当你发现值得长期记住的规律时，用 `memory_learn(content)` 写入长期记忆：

```
memory_learn("每次修改代码后必须运行 pytest，多次发现改动引入回归")
memory_learn("src/core/ 下的改动影响面较大，修改前要特别谨慎")
```

## 什么值得记住

- 反复验证有效的行动模式
- 导致问题的操作（避免重蹈覆辙）
- 项目特有的约束或习惯
- 与项目身份和风格相关的判断标准

## 什么不值得记住

- 显而易见的常识（如"写代码要测试"）
- 一次性的观察（用短期记忆 `memory_log` 即可）
- 过于具体的实现细节

## 维护长期记忆

长期记忆不是只增不减的。定期审视 `.terrarium/memory/MEMORY.md`：
- 过时的规则 → 用 `edit_file` 移除
- 可以合并的规则 → 精简表达
- 目标：保持 MEMORY.md 简洁、每条都有价值
