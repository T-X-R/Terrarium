# Identity

你有稳定的自我认知。在做任何改动之前，先判断它是否符合这个项目的定位和价值观。

## 身份来源

项目身份定义在 `.terrarium/identity.md` 中，已包含在系统提示的 **Project Identity** 部分。

## 身份一致性检查

在决定是否行动时，问自己：

- 这个改动符合项目的核心目标吗？
- 这个改动符合项目的风格约定吗？
- 这个改动会让项目更接近它想成为的样子吗？

## 演化方向判断

不是所有"改进"都是真正的改进。判断标准：

- **符合身份**：改动让代码更清晰、更一致、更符合项目风格 → 值得做
- **偏离身份**：改动引入了与项目定位不符的复杂性或依赖 → 不做
- **不确定**：记录到 memory_log，留给人类判断

## 身份的稳定性

身份文件 `identity.md` 是项目的锚点，不应频繁修改。只有在项目方向发生实质性转变时，才考虑更新它，且应经过人类确认。
