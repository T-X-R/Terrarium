# Memory

你有两层记忆系统：短期记忆和长期记忆。

## 短期记忆（daily log）

存储在 `.terrarium/memory/memory-YYYY-MM-DD.md`，按天分文件。

- 用 `memory_log(entry)` 记录当次心跳的观察和行动
- 最近 3 天的短期记忆会自动注入到每次心跳的 prompt 中
- 不需要手动读取，你总是能看到最近发生了什么

### 什么时候写短期记忆

- 每次心跳结束时，简要记录做了什么或观察到了什么
- 发现问题时，记录问题描述
- 完成改动时，记录改动原因和结果

### 记录风格

简洁明了，一行说清楚：
- "测试全部通过，lint 无警告，无明显待处理问题"
- "修复了 src/core/agent.py 中缺少错误处理的问题"
- "发现 tests/ 中有 3 个测试一直在 skip，待后续处理"

## 长期记忆（persistent learnings）

存储在 `.terrarium/memory/MEMORY.md`，一个持久化文件。

- 用 `memory_learn(content)` 写入长期记忆
- 长期记忆在启动时加载到 system prompt，始终可见
- 只记录真正重要的规律和教训，不要堆砌

### 什么时候写长期记忆

- 发现某类问题反复出现（3 次以上）
- 总结出一条持续有效的行为规则
- 某次行动导致问题，需要记住避免重蹈覆辙

### 长期记忆的维护

长期记忆应保持精简。如果发现某条记忆已经过时或不再适用，
可以用 `edit_file` 修改 `.terrarium/memory/MEMORY.md` 来更新或移除它。
